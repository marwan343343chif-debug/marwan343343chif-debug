## ◈ &nbsp;Eternal Memories &nbsp;`ETM`

<div align="center">

> *An anime-style open-world action RPG gacha game.*
> *Solo-developed. Adapted from an original completed novel.*
> *Built not for a market, but for a story that refused to stay on the page.*

</div>

<br/>

<details open>
<summary><b>▸ &nbsp;World Architecture</b></summary>
<br/>

| Layer | Name | Notes |
|:---:|---|---|
| `0` | *The Unnamed* | Hidden. Exists before existence. |
| `1–10` | Named Layers | Ascending power = ascending rank + knowledge |
| `∞` | The Labyrinth | Punishment realm. No exit by design. |

The cosmological fabric is woven from **Mysteries** — the fundamental currency of power. The **True History** is a shattered cosmic record; reading it is dangerous, surviving it rarer still.

</details>

<br/>

<details>
<summary><b>▸ &nbsp;Technical Systems</b></summary>
<br/>

| System | Implementation |
|---|---|
| ⚔️ **Combat** | `CombatStateManager` state machine · `ScriptableObject`-driven `DomainAttackOption` assets · Unity Input System action map swapping |
| 🎭 **VFX** | Shader Graph dissolve/materialization · VFX Graph particles · flipbook textures · pre-rendered Blender video overlays via `VideoPlayer` for signature ultimates |
| 🪞 **Dual-World Mirror** | WorldA / WorldB / BothWorlds layer masks · second camera rendering to `RenderTexture` · real-time simultaneous rendering of two realities |
| 🧠 **NeverLand Director** | `SanityLevel` float driving modular `IllusionEvent` ScriptableObjects · glitch shaders · phantom spawns with gaze-detection · impossible looping geometry · world-space floating text |
| 🌌 **Reactive Skybox** | `SkyState` ScriptableObjects · runtime skybox material swapping tied to world state |
| 🎬 **Cutscenes** | Pre-rendered Blender video overlays at Act endings — theatrical stillness as a deliberate solo-dev choice |
| 💬 **Dialogue** | Yarn Spinner–driven narrative · branching lore · reactive to player world state |

</details>

<br/>

<details>
<summary><b>▸ &nbsp;Development Philosophy</b></summary>
<br/>

```
Phase 1 ── Build the machine
            Architecture · Systems · Pipelines · Foundations
            Everything generic enough to hold any story.

Phase 2 ── Feed the machine
            Characters · Story · Content · World
            Everything specific to this one.

Revenue ─── Reinvested entirely.
            This is not a bet. It's a letter.
```

</details>

<br/>
