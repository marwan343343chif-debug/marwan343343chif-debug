## 🌌 Featured Project — Eternal Memories (ETM)

> *An anime-style open-world action RPG gacha game adapted from my own completed novel.*

| System | Details |
|---|---|
| 🌐 World | 10 named cosmic layers + a hidden 0th Layer + the Labyrinth |
| ⚔️ Combat | Real-time action with CombatStateManager & ScriptableObject-driven abilities |
| 🎭 VFX | Shader Graph dissolves · VFX Graph · flipbook textures · dimensional rifts |
| 🪞 Rendering | Dual-world mirror mechanic via layer culling masks + RenderTextures |
| 🧠 Sanity | NeverLand Director — a sanity-erosion system that reshapes the world |
| 💬 Dialogue | Yarn Spinner–driven narrative with branching lore |
| 🎬 Cutscenes | Pre-rendered Blender video overlays via Unity VideoPlayer at Act endings |
